### `~ whoami`

**Platform Engineer** — I make clusters boring so everything on top of them can be exciting.

Kubernetes & OpenShift · GitOps · observability · the unglamorous plumbing that keeps prod up at 3am.

</div>

---

Started as a backend engineer wrangling TypeScript, C#, Go and a fair amount of legacy PHP nobody wanted to touch. Somewhere between shipping services and getting paged for them, I got more interested in the layer *underneath* the app — how it's built, scheduled, rolled out, observed and kept alive.

These days I live in control planes and manifests: designing platforms on **Kubernetes** and **OpenShift**, wiring up GitOps pipelines, and treating reliability as a feature rather than an afterthought. Backend brain, platform hands.

Still curious, still breaking things in a lab so I don't break them in prod.
